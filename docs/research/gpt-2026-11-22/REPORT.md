The reported numbers imply that the generated field spends about 50 ms per rAF interval at 20 Hz and that the post-fix Matrix scenarios are about 24 ms and 21 ms at 41 and 47 Hz. ### 4. Matrix equivalence, reach and projection

Write \(T(\vec{p})=A\vec{p}\). For a curve \(C=\{\vec{c}(s):s\in D\}\), forward substitution gives exactly \(T(C)=\{A\vec{c}(s):s\in D\}\), including singular \(A\), provided the full relevant \(D\) is retained. Use \(\vec{c}(s)=(s,f(s))\) for \(y=f(x)\), \((g(s),s)\) for \(x=g(y)\) and \((r(s)\cos s,r(s)\sin s)\) for the polar curve on its original angular domain. Map explicit points/lists entrywise. A straight edge \((1-t)\vec{p}+t\vec{q}\) maps to the line segment between \(A\vec{p}\) and \(A\vec{q}\), so an affine map also preserves polygon boundaries and the filled image (with possible collapse for singular maps). Parametric plot domains, holes, restrictions, lists, marker semantics and Desmos’s \(t\) binding still need preservation.

For invertible \(A\), the image of \(F(\vec{p})\ \square\ 0\) is \(F(A^{-1}\vec{q})\ \square\ 0\) for the same relation \(\square\). A reflection preserves the comparison sign under substitution and reverses polygon orientation. The boundary alone cannot encode the included side, holes, strictness, or disjoint components. General implicit curves stay inverse unless a complete parameterization is verified. Polar regions also need the original signed-radius/angular semantics and a verified region rewrite. Singular maps have no inverse. An arbitrary implicit region may collapse to a segment or point set requiring projection with existence over the kernel. Keep the current unsupported/hybrid affordance unless that image can be represented exactly.

**Code to change.** `exactRoute.ts` already recognizes the above forward families and handles reserved \(t\). `MatrixSession.parametricReach()` derives one symmetric interval from a grid walk, rounds it to a power of two, and rebuilds the desired plan during sync. For an invertible linear map, pull the four viewport corners back by \(A^{-1}\). The min/max along the independent axis gives a conservative interval, since extrema of a linear functional on a rectangle occur at vertices. Use the true curve domain too. Add a cached guard band and refresh when the visible preimage leaves it, or on extent/transform changes. Off-center pans, high condition number, clipping, and singular maps need the current safe fallback or a separate proof of coverage. A very large interval can reduce Desmos sampling quality. Use the visible preimage interval’s size to choose whether to retain the inverse route and disclose how that decision affects the picture. A one-pixel budget should compare both the rendered curve and reference points all along visible branches.

In `redraw.ts`, cache flattened source branches by stable sketch revision, with a content/revision check when the host mutates in place. Keep viewport-closed inequality rings keyed by bounds, since their artificial closure depends on the view. In `MatrixLayer.ts` cache transformed math-space polylines, keyed additionally by map revision and pixel-tolerance bucket. Store packed coordinates and run offsets. For nonlinear maps, midpoint error already adapts to curvature. Add quarter-point checks for a midpoint alias (e.g. a sinusoidal warp with zero endpoint/midpoint deviations) and explicit breaks where the map becomes undefined. A Jacobian measures stretch and can trigger more sampling. A screen-space curvature bound or additional probes are needed to control chord error. Subdivision cannot recover portions of a source curve the host already clipped or undersampled. `Path2D` caching is worthwhile only if path construction dominates and the projection key is stable. Canvas transforms used to reuse paths must retain constant screen-pixel strokes/dashes. GPU paths only pay on a measured high-vertex workload and would need winding/even-odd fills, clipping, dashes, antialias and style parity.

**Private projection hook.** Sample a real pan and locate the grapher’s projection and draw-call identity from profiles. Check argument invariants, method ownership, item classes, clip space and whether x/y coordinate mapping happens separately. A shear/rotation couples x and y, so two independent scalar projection callbacks cannot implement it in general. Try a graph-geometry projection wrapper only for supported paired-coordinate paths. Leave axes, labels, hit targets, and images on their proper projection. Check original call/receiver behavior, store the original property descriptor and remove only your own wrapper. Activate only after a capability probe shows a known point transforms and host redraw still succeeds. On any mismatch retain normal Desmos drawing and show route status. A pure Canvas 2D affine transform changes stroke geometry and misses pre-clipped geometry, so treat it as a comparison candidate only. Estimate 3–6 days after a profile shows material upside.

### 7. Native-speed code and Desmos export

Rust or C++ can compile to packaged WebAssembly with an optional SIMD build. Native CPU instructions cannot be embedded and executed directly by ordinary extension JavaScript. A native-messaging host requires a separate OS install and permission. It can run locally, but violates the extension-only deployment requirement and adds IPC and cross-platform packaging, so it stays outside the comparison. Chrome’s page MAIN world uses the page CSP. Chrome’s isolated content script and extension document have distinct CSP rules. The November 9 offscreen test establishes a Chrome route with packaged source and `wasm-unsafe-eval`. The fork sets COOP/COEP on matching Desmos URLs, and the test observed isolation in its particular sessions. Gate the current page, extension page, and workers separately. A valid shared-memory constructor also needs an actual worker transfer/Atomics round trip before enabling threaded code. Represent a fallback as center \(a\), exact coefficients or recurrence, convergence domain, and a remainder function. For \(f(x)=\sum c_n(x-a)^n\) with positive radius \(R\), uniform convergence on compact intervals inside \(|x-a|<R\) justifies integration termwise. The result is \(C+\sum c_n(x-a)^{n+1}/(n+1)\). ### 4. Precise values

Two input paths share the same panel. **Sequence or sum** accepts the summand or enough indexed \(S*n\) values, the index/start, and optional expected constant or asymptotic model. Prove convergence and compute an enclosure for the tail where possible. **Value** accepts a decimal or exact expression and an optional target. From a single decimal with no error or tail model, a limit is underdetermined. The tool can compare the decimal’s rounding interval to a target and find compact candidates that fit the supplied digits. It cannot infer the unseen sequence. For example, for \(S*{40}=\sum*{n=1}^{40}n^{-2}\), the integral test gives \(1/41 \le \pi^2/6-S*{40}\le 1/40\). Use the tail interval before testing digits against a proposed value.

Build candidate atoms from the normalized expression and user hints, with an optional supplemental palette of \(\pi,e,\log p,\zeta(k),G,\gamma\) and algebraic atoms. Deduplicate exact dependencies and keep basis dimension and relation height bounded or user-adjustable. Reuse existing recognition shapes and continued fractions before PSLQ. Signed values and zero need explicit guards before log-product recognition. For each overlap, report error bounds or residual magnitude, significant digits supported, relation coefficient norm, basis size, source/candidate distinction and how many basis searches ran. Higher precision can test a relation found from an actual generating expression. Reformatting a 16-digit decimal to 80 digits adds no evidence. Show “Matches within supplied precision” until a theorem/certificate proves identity.

Select acceleration from the sequence’s structure. Richardson assumes a controlled asymptotic expansion, Aitken or Wynn \(\varepsilon\) may help geometric-like error, and Levin \(u\) needs credible remainder estimates. Euler–Maclaurin is suitable with available smooth derivatives and a bound on the remaining correction/tail. Monitor denominator cancellation and stability under extra terms. For a slowly convergent series, show the raw partial sum, the accelerated estimate and the rigorous enclosure separately. Verify identity with a theorem or independent symbolic derivation and use the PSLQ residual as numerical evidence. Test adversarial decimals that fit multiple constants, a slowly converging sequence, a divergent sequence that looks stable over 40 terms, and zero/sign handling. [PSLQ analysis](https://ntrs.nasa.gov/citations/19970009839)
