Vector Tools · Matrix tab

Mock-up, not built

Desmos's 2D calculator now has matrices, but it does not draw vectors. This tab would apply a map to the whole graph, either a 2×2 matrix A or any formula T(x, y). It carries along every curve, point and shaded region, plus the grid and your vectors. Turn it off to see the graph as typed. Drag the gray arrow tips and the purple probe, or scrub from doing nothing to the full map.

      Measured in live Desmos, 2026-10-22. A·(1,2) with
      A=[[1,2],[3,4]] is the point (5, 11), drawn.
      A·[1;2] is the column [5; 11], not drawn.
      vector(…) is refused in 2D. A·[x;y] is refused
      (“too many variables”), so Desmos cannot draw the field Ax itself;
      the Field toggle would draw it on the GPU, as the Field tab does now.
    

    

      How the real tab would transform everything. Desmos keeps every
      curve, point and shaded region it has drawn as polylines in graph
      coordinates (grapher2d.graphSketches, measured). The tab
      would send each vertex through T, after subdividing long segments
      so a nonlinear map can bend them, and draw the result over the paper. It
      would hide the originals, or keep them faint. Desmos only samples what is
      on screen, though, and its headless calculator has no grapher to sample
      more. So a map that pulls far-away points inward, like the fisheye, would
      show an empty rim. This mock-up samples a wide box to show the intended
      look.
    

    

      Both routes, behind the “Drawing the graph” toggle.
      Exact rewrites each expression with (x, y) replaced
      by T⁻¹(x, y), and Desmos draws the result itself,
      inequalities included, sharp all the way to the edge. Here that is
      emulated faithfully: each curve is plotted as the points q where
      F(T⁻¹(q)) = 0. It needs an inverse. Every matrix with
      det ≠ 0 has one; of the formula presets, Swirl and Fisheye do, and Wave,
      z² and Polar do not. With a formula, it draws the finished map only, since
      the in-between maps have no formula for their inverse. Redraw works
      for any map and scrubs smoothly. Here it samples only the visible window,
      as Desmos does, so the empty band you see at the edge is real. The tab
      falls back to Redraw by itself when there is no inverse, and says so.
